# 借書認證隨身查

臺中市閱讀認證系統的手機輔助頁：匯入由電腦擴充功能匯出的「已通過書單」（`reading-passed.json`），在圖書館用鏡頭掃 ISBN 或輸入書名，離線確認是否已認證；也可以一鍵送到官方查詢頁確認可否認證。

- 頁面本身不含任何個人資料；匯入的書單只存在這支手機的瀏覽器（localStorage），不會上傳。
- 頁面不向任何伺服器送出資料（CSP `connect-src 'none'`）；表單只能送到 `https://read.tc.edu.tw`。
- 右上角「☰ 書單」側邊選單可匯入或清除書單；掃描紀錄（最多 300 筆）只存在這支手機的瀏覽器，可篩選、再查一次、刪除與復原。
- 條碼掃描使用 html5-qrcode 2.3.8，以 SRI 驗證檔案完整性。

非官方工具，與臺中市政府教育局無關。
